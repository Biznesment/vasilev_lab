# Choicer с редактированием

Копия проекта «Choicer с редактированием» (http://1.nikpv.z8.ru/choicer1/) — мобильное
приложение-выборщик на **React + Onsen UI**:

```
Тема → Подтема → Содержание (главы)
```

Стек и структура повторяют оригинал: React 18, `react-onsenui` (Navigator, Page, List,
Toolbar, Modal, notification), `onsenui` 2.12 со встроенными стилями и иконочными
шрифтами. Сборка — Vite (в оригинале был webpack).

## Возможности

- Три уровня навигации с анимацией перехода страниц (Navigator).
- Список **Тем** (Лесков Н.С., Толстой Л.Н., Достоевский Н.С.).
- Список **Подтем** выбранной темы с «хлебной крошкой» в тулбаре (обрезается до 20 символов).
- Список **Глав** подтемы с ручным изменением порядка (кнопки ↑ / ↓ для выделенной строки).
- Режим редактирования на каждом экране (иконка карандаша):
  - добавление темы (кнопка «+» → `ons.notification.prompt`);
  - переименование строки (поле ввода + подтверждение галочкой / Enter);
  - удаление строки с каскадным удалением вложенных подтем и глав;
  - модальное окно «Сохранение… / Удаление…» на время операции.
- Каскадное удаление и работа с `ord`/`id` вынесены в `src/Loader.js`.
- Состояние хранится в памяти компонента, как в оригинале (перезагрузка возвращает
  исходные данные из `src/data.js`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр собранного dist/
```

Сборка использует `base: './'`, поэтому `dist/` можно выложить в любой подкаталог
(например, `/choicer1/`) — пути к ассетам будут относительными.

## Структура

```
index.html
vite.config.js
src/
  index.jsx              — точка входа, инициализация Onsen UI
  data.js                — исходные данные: темы, подтемы, главы
  Loader.js              — add / del / editSubThemes / sorted (работа с ord и id)
  components/
    Choicer.jsx          — Navigator и все операции над данными
    ThemesList.jsx       — экран «Тема»
    SubThemesList.jsx    — экран «Подтемы»
    Contents.jsx         — экран «Содержание» + сортировка ↑/↓
    EditableItem.jsx     — строка с полем ввода в режиме редактирования
    EditDelItem.jsx      — строка с кнопками «изменить» / «удалить»
    BusyModal.jsx        — модальное окно ожидания
```
