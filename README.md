# Открывашка (BeerOpener) — Android (Kotlin + Jetpack Compose)

Простое и наглядное Android-приложение на **Kotlin** и **Jetpack Compose (Material 3)**, в котором нужно открывать бутылку пива свайпом вверх по крышке или нажатием кнопки.

## Возможности
- **Интерактивное открытие бутылки**:
  - свайп вверх по крышке с визуализацией рычага открывашки и наклона крышки;
  - кнопка **«Открыть пиво»** / **«Следующая бутылка»** для быстрого открытия.
- **Кастомная графика и анимации на `Canvas`**:
  - стеклянная бутылка с бликами, уровнем напитка, пузырьками газа и этикеткой;
  - анимация улетающей крышки, брызг газа и поднимающейся шапки пены (`animateFloatAsState`, `rememberInfiniteTransition`, `spring`).
- **Выбор сорта напитка** (`Светлое`, `Пшеничное`, `Тёмное`) с изменением оттенка стекла, напитка, пены и крышки.
- **Счётчик открытых бутылок** с кнопкой сброса и сохранением состояния при повороте экрана (`ViewModel` + `StateFlow`).
- **Виброотклик и звук открытия** («чпок» + шипение пены через стандартный `AudioTrack` без сторонних библиотек и аудиофайлов, с возможностью отключения).

## Архитектура и структура проекта
```text
app/src/main/java/com/vasilev/beeropener/
├── MainActivity.kt                  # Точка входа (ComponentActivity + Compose)
├── model/
│   └── BeerSort.kt                  # Перечисление сортов напитка и цветов
├── sound/
│   └── PopSoundPlayer.kt            # Генерация звука открытия через AudioTrack
└── ui/
    ├── BeerOpenerScreen.kt          # Главный экран (Material 3 UI)
    ├── BeerOpenerViewModel.kt       # Состояние экрана (MVVM: ViewModel + StateFlow)
    ├── components/
    │   └── BeerBottleView.kt        # Отрисовка бутылки, пены, крышки и жестов
    └── theme/                       # Цветовая схема и типографика Material 3
```

## Как запустить в Android Studio
1. Откройте **Android Studio** (Ladybug `2024.2` или новее).
2. Выберите **File → Open...** и укажите корневую папку проекта `vasilev_lab`.
3. Дождитесь завершения синхронизации **Gradle Sync**.
4. Запустите приложение на эмуляторе или подключённом Android-устройстве (**Run 'app'**, `Shift + F10`, Android 7.0 / API 24+).

## Сборка APK из командной строки
```bash
./gradlew assembleDebug
```
Готовый APK появится по пути:
`app/build/outputs/apk/debug/app-debug.apk`
